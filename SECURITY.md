# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's
[private vulnerability reporting](https://github.com/ventstream/ventstream-releases/security/advisories/new)
form. Include the affected version, operating system, reproduction steps, and
the potential impact.

Do not include production credentials, access tokens, customer data, or other
secrets in a report.

## Supported releases

Security fixes are applied to the latest release. Older binaries remain
available for rollback, but users should upgrade to the latest patched release.
